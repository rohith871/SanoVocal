# Data Sources

## Primary datasets

1. BharatSchemes Dataset v1
https://huggingface.co/datasets/Banothuarpitha/bharatschemes-v1

2. India Government Schemes - Multilingual QA Dataset
https://huggingface.co/datasets/Aditipatil56/adaption-india-govt-schemes-qa

3. MyScheme structured dataset
https://huggingface.co/datasets/shrijayan/gov_myscheme

## Data strategy

- Use existing datasets as seed data
- Filter to 25-40 high-impact schemes
- Clean and deduplicate records
- Verify key claims against official government sources
- Build grounded Q&A and agent trajectories
- Keep evaluation data separate from training data
